# Company and Location Preparation Plan

The same fundamentals recur across European offices, but the role emphasis changes by team. Treat this as a preparation map, not a promise of exact interview questions.

## Meta

### Software / Product Engineering

- Arrays, strings, hashing, graphs, trees, recursion, dynamic programming.
- Strong focus on communicating trade-offs and testing edge cases.
- Practice writing compilable code without relying on an IDE debugger.
- Prepare medium and selected hard problems under time pressure.

### AI Engineering / Applied AI

- Everything above, plus Python fluency and data manipulation.
- Model-serving APIs, batching, caching, queues, rate limits, observability.
- Retrieval, embeddings, ranking, evaluation, prompt/version management.
- Discuss latency, throughput, cost, privacy, safety, and failure modes.

### FDE / Forward Deployed Engineering

- Coding and debugging in an unfamiliar codebase.
- API integration, SQL, data pipelines, authentication, webhooks, retries.
- Customer discovery, translating ambiguous requirements, and shipping an MVP.
- Incident response, migration planning, documentation, and stakeholder communication.

## Comparable companies and role families

### Google / DeepMind

Emphasize algorithms, distributed systems, ML fundamentals, experiment design, and clear mathematical reasoning.

### Microsoft / Azure / Copilot

Emphasize coding fundamentals, cloud architecture, APIs, reliability, security, and production AI integration.

### Amazon / AWS

Emphasize data structures, scalable services, operational excellence, customer obsession, and behavioral examples using metrics.

### OpenAI / Anthropic / Cohere / Mistral

Emphasize software quality, model and inference concepts, evaluations, data quality, safety, observability, and rapid prototyping. Team-specific expectations vary substantially.

### Databricks / Snowflake / Confluent

Emphasize distributed data systems, SQL, streaming, storage, partitions, consistency, and performance debugging.

### Scale AI / Hugging Face

Emphasize data pipelines, model tooling, evaluation, developer experience, open-source collaboration, and customer or partner delivery.

### Palantir

Emphasize forward-deployed problem solving, data integration, product thinking, deployment in imperfect environments, and communication with technical and non-technical users.

### Nvidia / Graphcore / AI infrastructure teams

Emphasize systems programming, concurrency, memory, performance, distributed training/inference, and hardware-aware trade-offs.

## Geography notes

### London

Prepare for broad product and platform teams, customer-facing communication, system design, and behavioral depth. Be ready to explain impact across multiple stakeholders.

### Luxembourg

Prepare for data, cloud, logistics, payments, infrastructure, and multilingual stakeholder settings. SQL, distributed systems, reliability, and compliance discussions can be valuable.

### Germany

Prepare for platform engineering, automotive/industrial AI, infrastructure, privacy, reliability, and structured engineering processes. Clarify language expectations with the recruiter.

### Netherlands

Prepare for product engineering, payments, logistics, cloud, data, and highly collaborative English-language teams. Emphasize ownership, pragmatic delivery, and measurable outcomes.

## Questions to ask the recruiter

1. Is the coding interview language-agnostic, and may I use C++ or Python?
2. Is the role product engineering, applied AI, solutions engineering, or forward-deployed?
3. Will there be SQL, debugging, API integration, or a take-home exercise?
4. How much system design is expected at this level?
5. Does the loop include a customer presentation or technical deep dive?
6. Which location and team will own the final hiring decision?
7. Are relocation, visa, language, or travel expectations part of the role?
8. What production metrics define success in the first six months?
